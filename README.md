# QR Code Generator

A simple and responsive web application that allows users to generate QR codes from URLs. Enter a URL, click the generate button, and instantly get a QR code that can be scanned using a smartphone.

## Features

- Generate QR codes from user-provided URLs.
- Simple and beginner-friendly interface.
- Instant QR code generation.
- Input validation to prevent empty submissions.
- Uses a JavaScript QR code library.

## Technologies Used

- **HTML5** – Structure of the webpage.
- **CSS3** – Styling and layout.
- **JavaScript** – Application logic and interactivity.
- **QRCode.js** – QR code generation library.

## How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `index.html` in your web browser.

4. Enter a URL in the input field.

5. Click the **Generate QR Code** button.

6. Your QR code will appear on the webpage.

## How It Works

1. The user enters a URL into the input field.
2. JavaScript retrieves the entered URL.
3. The application checks whether the input is empty.
4. QRCode.js converts the URL into a QR code.
5. The generated QR code is displayed on the webpage.
